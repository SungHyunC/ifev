# 실제 주행 기록 수집 가이드 (PT 전 검증용)

**목적**: 4주 데이터가 가상이라는 약점을 메웁니다. 실제 사람의 2~4주 주행을 이프EV와 같은 엔진에 넣어 판정을 보여 주고, 전기차 차주의 실제 충전량과 예측을 비교합니다.

**일정**: 오늘 시작 → 11/30까지 최소 2주 → 12/1 변환·재생 → 12/3 PT.

**필요한 사람**
- **A그룹 (내연기관·하이브리드 차주) 2~3명**: 팀원, 가족, 지인. 판정 사례가 됩니다.
- **B그룹 (전기차 차주) 1~2명**: 예측 오차를 잴 수 있습니다. 아이오닉 5·6, 코나, 캐스퍼면 앱 차종과 바로 맞습니다.

---

## 1. 참가자에게 보낼 안내 (그대로 복사해 보내도 됩니다)

> 안녕하세요. 차량용 앱 공모전 검증에 2주만 도와주세요.
> 1. 폰에 GPS 기록 앱을 설치합니다.
>    - 안드로이드: **GPSLogger** (무료·오픈소스, Play 스토어 또는 F-Droid)
>    - 아이폰: **Open GPX Tracker** (무료·오픈소스, App Store)
> 2. **내 차를 직접 운전할 때만** 출발 전에 기록을 켜고, 도착하면 끕니다. 동승하거나 대중교통을 탈 때는 켜지 않습니다.
> 3. 일주일에 한 번 기록을 GPX 파일로 내보내 보내 주세요.
> 4. 처음에 한 번만 알려 주세요.
>    - 차종
>    - 계기판의 평균 연비(km/L)
>    - 집이나 아파트에서 전기차를 충전할 수 있는지(가정)
> 5. (전기차 차주만) 기록 기간의 첫날과 마지막 날에 배터리 %를 적어 주세요. 그 사이 충전할 때마다 날짜와 충전량(kWh)을 적어 주세요. 충전 앱 내역 캡처도 괜찮습니다.
>
> 기록에는 위치가 들어 있지만, 받는 즉시 변환해 **위치 좌표는 지우고** 주행 거리·시간과 집/회사/기타 구분만 남깁니다. 원본 GPX는 변환 후 삭제합니다. 이름은 "참가자 A"처럼만 표시합니다.

**앱 설정 권장값**
- GPSLogger:
  - 기록 간격(Log every) 5초, 거리 필터 0m
  - Log to GPX 켬
  - 시작할 때 "Start logging"
- Open GPX Tracker: 시작 버튼으로 기록하고, 끝나면 저장합니다.

## 2. 동의 받기 (짧은 문구)

> 나는 공모전 검증을 위해 내 차 주행 GPS 기록을 2~4주 제공하는 데 동의합니다. 기록은 변환 즉시 좌표가 지워지고 주행 거리·시간·집/회사/기타 구분만 남으며, 원본은 삭제됩니다. 결과는 "참가자 A" 등 익명으로 발표 자료에 쓰일 수 있습니다. 언제든 철회할 수 있습니다. (이름, 날짜, 서명)

## 3. 받은 기록 변환하기

```bash
# 사람마다 폴더 하나. GPX/CSV를 넣고:
python3 tools/gpx_to_trips.py 받은기록/참가자A/ --out drives/A/trips.json --fuel 12.4
# 집·회사는 기록에서 추정합니다(화면에는 100m 단위로 흐린 좌표만 표시). 틀리면 --home 위도,경도 --office 위도,경도
```

`drives/A/profile.json`을 만듭니다. 형식은 `tools/profile.example.json`을 참고합니다.

```json
{"label": "참가자 A · 그랜저", "homeCharging": true, "fuelKmPerL": 12.4}
```

전기차 차주는 `drives/B/ev_actual.json`을 추가합니다. 형식은 `tools/ev_actual.example.json`을 참고합니다.

```json
{"modelId": "ioniq5-long", "chargedKwh": 182.0, "startSoc": 80, "endSoc": 64}
```
- `chargedKwh`: 기간 동안 충전한 양의 합
- `startSoc`, `endSoc`: 첫날과 마지막 날의 배터리 %
- 차종 id: `casper-electric`, `kona-electric`, `ioniq5-long`, `ioniq6-standard`, `ioniq6-long`, `ioniq9-2wd`

변환이 끝나면 원본 GPX를 지웁니다.

## 4. 엔진으로 재생하고 검증하기

```bash
./gradlew :app:testDebugUnitTest --tests '*RealDriveReplay*' -Pdrives=$(pwd)/drives --rerun
```

`drives/report.md`가 생깁니다.
- 사람마다 현대 전기차 6종의 판정, 30일 충전 횟수, 절감액, 신뢰도가 나옵니다.
- 전기차 차주는 **실제 사용 kWh와 이프EV 예측 kWh의 오차**가 함께 나옵니다.
- 오차가 25%를 넘으면 공조 비율(`--climate`)과 GPS 거리 누락부터 확인합니다.

## 5. 앱에서 보여 주기 (PT)

```bash
mkdir -p app/src/main/assets/real/A
cp drives/A/trips.json drives/A/profile.json app/src/main/assets/real/A/
./gradlew :app:assembleRelease
```

`drives/`와 `app/src/main/assets/real/`은 `.gitignore`에 있어 저장소에 올라가지 않습니다(PT용 APK는 로컬에서 빌드). 시연 모드에 **④ 실제 기록 · 참가자 A** 버튼이 생깁니다. 확정 리포트에는 "실제 주행 기록 · 폰 GPS로 수집" 배지가 붙습니다. 이 폴더가 없으면 버튼도 나타나지 않습니다.

## 6. PT에서 말할 것
- 실제인 것과 가상인 것을 나눠서 말합니다.
  - 실제: 참가자 n명의 n주 주행
  - 수집 방식: 차 대신 폰 GPS
  - 가정: 공조 비율, 서울 평년 기온
- 전기차 차주 검증 결과는 "예측 오차 ±n%"로 한 줄에 말합니다. 표본이 작다는 점도 같이 말합니다.
